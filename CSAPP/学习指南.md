## 边听边写的方法

1. 每听完一个小主题，暂停，用自己的话写清楚它解决什么问题。
2. 配一个能手算的例子，记录输入、执行过程和输出。
3. 把暂时不懂的地方写成具体问题，保留“待确认”，不要猜成结论。
4. 看完后合上课件，做一道变式题；能预测结果并解释原因，再继续下一节。
5. 整理博客时保留个人理解，并补上成立条件、反例和来源。

每次提问可附：课件页码或视频时间、代码片段、自己的理解、具体卡住的一步。讨论后把解释整理回对应段落。

## 前两篇待复习的准确性问题

以下是复习清单，尚未改动原文。

* **截断与取模**：`100101` 作为6位补码是 -27，截为4位得到 `0101`。应先按模 `2^4 = 16` 求低4位，再按补码解释；原文的模8应改为模16。这里的数学模得到0到15之间的余数，不等同于 C 对负数使用 `%` 的结果。
* **负数取模的表述**：余数 `r` 应满足 `x - r` 能被模数整除。例如 `-27 - 5 = -32` 能被16整除。
* **机器运算与 C 语义**：固定宽度机器加法会保留低位；C 的有符号整数溢出属于未定义行为，不能直接据此推导 C 程序必然回绕。
* **混合有符号与无符号运算**：同等级的 `int` 和 `unsigned int` 通常转成无符号；完整规则还涉及整数提升、类型等级和表示范围，不能推广为所有有符号类型必然转无符号。
* **移位**：C 的移位限制取决于整数提升后的左操作数类型宽度。不要把8位存储对象直接理解成8位移位运算；机器移位计数规则也不等同于 C 语言规则。
* **NaN**：它表示“非数”，不是乱码；例如在实数浮点运算中，某些无有效数值结果的运算会产生 NaN。
* **向偶数舍入**：它减少中点舍入反复偏向同一方向的偏差，并不保证任意数据集向上和向下舍入的概率各为50%。
* **浮点数举例**：舍入与运算性质的例子应注明使用 `float` 还是 `double`，避免把某一精度下的结果推广到所有浮点格式。
